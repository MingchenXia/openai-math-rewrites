# Interpolation checks

Run `python3 check_interpolation.py` from this directory with assertions enabled. The script uses only Python’s standard library and a fixed random seed for the row examples.

It checks the ranks of 132 stretched-simplex jet matrices over several finite fields and 90 horizontal-row evaluation matrices over the field with 101 elements. These computations check examples of the formulas. The general statements are proved in the manuscripts.
